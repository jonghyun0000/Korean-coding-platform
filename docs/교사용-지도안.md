# 한글코딩 놀이터 — 교사용 지도안 (12차시)

- 대상: 초등학교 5~6학년 (4학년도 가능, 아래 '학년별 조정' 참고)
- 총 12차시 × 40분 = 8시간
- 준비물: 인터넷 브라우저가 있는 컴퓨터/노트북/태블릿 (설치·로그인 없음)
- 관련 교과: 실과 「디지털 사회와 인공지능」

> ⚠️ **성취기준 확인 안내**
> 아래 성취기준 코드와 문구는 2022 개정 교육과정 실과(5~6학년군) '디지털 사회와 인공지능' 영역을 기준으로 정리했습니다.
> 학교 교육과정 문서·교과서와 한 번 대조해 확인한 뒤 사용해 주세요.

## 2. 왜 '한글 텍스트 코딩'인가

| | 블록 코딩(엔트리·스크래치) | **한글코딩 놀이터** | 파이썬 |
|---|---|---|---|
| 입력 방식 | 마우스로 끌어 놓기 | 키보드로 타이핑 | 키보드로 타이핑 |
| 언어 | 한글 블록 | **한글 낱말 (영어도 가능)** | 영어 |
| 문법 오류 | 생기지 않음 | 생김 (**한글로 친절히 안내**) | 생김 (영어 오류 메시지) |
| 다음 단계 | → 텍스트 코딩 | → **파이썬** | — |

블록에서 텍스트로 넘어갈 때 아이들이 만나는 벽은 두 가지입니다: **① 영어 낱말**과 **② 무서운 오류 메시지**.
이 프로그램은 그 둘을 한글로 낮춘 다리입니다. 동시에 모든 낱말에 영어 짝을 붙여 두어(`만약 = if`),
마우스를 올리기만 하면 실제 코딩 낱말을 자연스럽게 익힙니다.

## 4. 수업 준비

### 4-1. 접속 주소 만들기

| 상황 | 주소 |
|---|---|
| 학생용 (평소) | `https://<배포주소>/` |
| **공용 PC 정리 후 시작** | `https://<배포주소>/?reset=1` |
| **교사용 (정답·지도안 표시)** | `https://<배포주소>/?teacher=1` |

컴퓨터실 바탕화면 바로가기를 **`?reset=1`** 주소로 만들어 두면, 매 교시 이전 학생의 코드·뱃지가 지워진 깨끗한 상태로 시작합니다.

> `?teacher=1` 화면에는 **예시 답안 코드와 퀴즈 정답**이 들어 있습니다. 교사 컴퓨터에서만 사용해 주세요.

### 4-2. 오프라인/교내 서버 배포

인터넷이 없거나 외부 사이트가 차단된 교실에서도 그대로 씁니다.
글꼴까지 포함해 **외부로 나가는 요청이 하나도 없습니다.**

```bash
npm install
npm run build
# 생성된 dist/ 폴더를 교내 서버나 USB에 그대로 복사
```

### 4-3. 개인정보

- 학생이 쓴 코드·뱃지·진도는 **그 브라우저 안에만(localStorage)** 저장됩니다.
- 서버로 전송되는 정보가 **없습니다.** 회원가입·로그인도 없습니다.
- 이름·학년/반은 [내 진도] 창에서 **선택적으로만** 입력하며, 이것도 브라우저 안에만 남습니다.
- 기기를 바꾸면 자료가 따라가지 않습니다 → [내 진도] → [파일로 저장] / [파일 불러오기]를 안내해 주세요.

## 5. 평가

### 5-1. 과정 평가 (매 차시)

화면 상단의 **[진도 뱃지]** 를 누르면 학생이 자기 진도표를 볼 수 있습니다.
`[글로 복사하기]` 로 복사해 학급 게시판·패들렛에 붙이게 하거나, `[인쇄하기]` 로 종이 제출을 받을 수 있습니다.

> ℹ️ 진도 판정은 **시작 코드를 그대로 실행만 해서는 완료되지 않도록** 설계되어 있습니다.
> 주석에 낱말만 적어 두는 방식으로도 통과되지 않습니다. 다만 완료 표시는 참고 자료이고,
> **결과물(코드·그림)을 직접 보는 것**이 가장 정확합니다.

### 5-2. 총괄 평가 루브릭 (12차시 종료 시)

| 평가 요소 | 잘함 | 보통 | 도움 필요 |
|---|---|---|---|
| **순차·반복·선택** | 세 구조를 목적에 맞게 조합해 문제를 해결한다 | 예시를 변형해 각 구조를 사용한다 | 구조의 뜻은 알지만 스스로 쓰지 못한다 |
| **문제 해결 절차** | 만들 것을 먼저 계획하고 단계로 나눈다 | 예시를 따라 하며 필요한 부분을 고친다 | 무엇부터 할지 정하기 어려워한다 |
| **디버깅 태도** | 오류 메시지를 읽고 스스로 원인을 찾는다 | 도움을 받아 오류를 고친다 | 오류가 나면 멈춰 버린다 |
| **협력·공유** | 자기 코드를 친구에게 설명하고 서로 개선한다 | 결과물을 공유한다 | 개인 활동에 머문다 |

차시별 세부 루브릭은 화면 **[교사용]** 창의 각 차시 항목에 있습니다.

### 5-3. 산출물 평가

12차시 작품은 **[그림 저장]** 버튼으로 PNG 파일로 내려받을 수 있습니다.

## 8. 파이썬으로 넘어갈 때

이 프로그램의 모든 낱말에는 영어 짝이 있고, **영어로 써도 그대로 실행됩니다.**

```
반복 i = 1 부터 4          for i = 1 to 4
    캐릭터.앞으로(100)   =     turtle.forward(100)
    캐릭터.오른쪽(90)          turtle.right(90)
끝                          end
```

`print` · `if` · `for` · `def` · `turtle.forward` 는 **파이썬에서도 같은 낱말**입니다.
다만 파이썬은 블록을 `끝`(`end`)으로 닫지 않고 **콜론(:)과 들여쓰기**로 나눕니다.
에디터에서 낱말에 마우스를 올리면 이런 차이를 그때그때 알려 줍니다.

12차시를 마친 학생에게는 다음 순서를 권합니다.
① 영어 낱말로 같은 코드 다시 써 보기 → ② 파이썬 `turtle` 모듈로 옮겨 보기 → ③ 콜론과 들여쓰기 배우기

## 9. 언플러그드 활동 모음 (도입용)

| 차시 | 활동 |
|---|---|
| 1 | **로봇 놀이** — 짝에게 종이접기를 말로만 시키기. 애매한 지시가 왜 실패하는지 체감 |
| 2 | **이름표 상자** — 상자에 이름표를 붙이고 쪽지를 넣었다 꺼내기 |
| 3 | **질문 카드** — 카드의 질문을 짝에게 하고 답을 빈칸에 적어 문장 완성 |
| 4 | **조건 술래잡기** — 조건에 해당하는 학생만 앞으로 한 걸음 |
| 5 | **사람 거북이** — 바닥 테이프 사각형을 "앞으로-오른쪽 90도"로 걷기 |
| 6 | **별 그리기** — 원 위 점 5개를 두 칸씩 건너뛰며 잇기 |
| 7 | **번호 손뼉** — 줄지어 번호를 부르며 짝수만 손들기 |
| 8 | **업다운 게임** — 몇 번 만에 맞혔는지 세고 반씩 좁히는 전략 이야기 |
| 9 | **레시피 카드** — 카드 이름만 부르면 같은 과정을 반복 |
| 10 | **0번 의자** — 의자에 0번부터 번호표 붙이기 |
| 11 | **좌표 그림** — 모눈종이에 좌표를 불러 주고 점 찍어 그림 완성 |
| 12 | **설계 먼저** — 만들 그림을 종이에 스케치하고 필요한 명령 목록 적기 |

## 10. 문법 요약 (인쇄해서 나눠 주기)

```
출력("안녕")              화면에 보여주기          print
이름 = 입력("이름은?")    물어보고 글자로 받기      input
나이 = 숫자입력("몇 살?") 물어보고 숫자로 받기      inputNumber
이름 = "민준"             상자에 값 넣기

만약 나이 >= 10 이면 … 아니면 … 끝        if … then … else … end
반복 i = 1 부터 5 … 끝                    for i = 1 to 5 … end
동안 i < 10 … 끝                          while … end
함수 더하기(a, b) … 반환 a + b … 끝       def … return … end
숫자들 = [1, 2, 3]   숫자들[0]  길이( )  추가( )    첫 칸은 0번!

캐릭터.앞으로(100)   캐릭터.오른쪽(90)   캐릭터.색깔("빨강")
캐릭터.원(50)        캐릭터.이동(100, 50)  캐릭터.집으로()
캐릭터.채우기시작() … 캐릭터.채우기끝()   캐릭터.글쓰기("안녕")
캐릭터.펜올리기()    캐릭터.펜내리기()     캐릭터.숨기기()
```

색: 빨강 주황 노랑 초록 연두 파랑 하늘 남색 보라 분홍 갈색 검정 하양 회색 (영어 이름도 가능)
