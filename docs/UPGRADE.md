# 예제 실험실과 저장 안정성 개선

## 예측 → 설명 → 실행

예제 실험실에서 3–10 사이 숫자를 바꿀 수 있습니다.

- 도형: 변의 수가 늘어날 때 `360 / 변` 회전 각도의 변화 확인
- 누적 합: `1`부터 선택한 수까지 더해 가는 과정을 출력

설명을 보기 전에 먼저 결과를 예상하도록 구성했습니다. 에디터에 넣기 전 기존 코드 교체를 확인하며, 넣은 후 실험실을 접어 코드와 그림판에 집중할 수 있습니다. 기존 미션 판정은 유지합니다.

## 저장 처리

300ms 지연 저장에 미션 ID를 고정하고, 예제 코드로 교체할 때 대기 중인 이전 저장을 취소합니다. 페이지를 떠나거나 탭이 숨겨질 때 현재 코드를 저장합니다. 브라우저 저장 공간이 제한된 경우 영구 저장은 보장할 수 없습니다.

## 검증

`npm ci` → `npm run smoke` → `npm test` → `npm run build`

- 기존 언어·미션 스모크 검사: 150개
- 새 실험 검사: 도형 8종의 이동 수와 총 회전각, 누적 합 8종의 출력과 합계
- GitHub Actions에 동일 검사를 등록

이 검사는 문법과 예제 동작을 확인합니다. 교육 효과는 실제 학습자 관찰과 별도의 평가가 필요합니다.

## 다음 학습 과제

언어를 더 확장하기 전에 렉서 → 파서 → 인터프리터 흐름을 작은 예제와 테스트로 이해하고, 학습자의 막힘을 관찰해 안내를 다듬습니다. 이 프로젝트는 AI 도구를 활용해 구현·개선하고 있습니다.
