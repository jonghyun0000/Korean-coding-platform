# 가정통신문 — 「한글코딩 놀이터」로 코딩을 시작합니다

안녕하세요, 학부모님.

이번 학기 실과 시간에 **「한글코딩 놀이터」** 로 코딩 수업을 진행합니다.
가정에서도 같이 해 보실 수 있도록 안내드립니다.

---

## 어떤 프로그램인가요?

- 브라우저에서 바로 열리는 **무료 학습 사이트**입니다. 설치·회원가입·로그인이 없습니다.
- 명령어가 모두 **한글**입니다. `출력("안녕")`, `반복 i = 1 부터 4` 처럼 읽으면 뜻이 보입니다.
- 코드를 실행하면 **거북이 캐릭터가 화면에 그림을 그립니다.** 코드 한 줄이 어떤 변화를 만드는지 눈으로 봅니다.
- 오류가 나도 어려운 영어 대신 **"3번째 줄에 '끝'을 안 적었어요"** 처럼 아이 눈높이로 알려 줍니다.

## 접속 주소

```
https://<학교에서 안내한 주소>
```

스마트폰보다 **컴퓨터나 태블릿 + 키보드**를 권합니다(타이핑 연습이 학습의 일부입니다).

---

## 무엇을 배우나요? (12차시)

| 차시 | 배우는 것 |
|---|---|
| 1~3 | 명령 내리기, 값을 담는 상자(변수), 컴퓨터가 나에게 물어보기(입력) |
| 4~6 | 조건에 따라 고르기, 반복해서 도형 그리기, 각도와 도형의 관계 |
| 7~8 | 반복과 조건을 함께 쓰기, 맞힐 때까지 반복하는 게임 만들기 |
| 9~10 | 나만의 명령 만들기(함수), 여러 값을 다루기(리스트) |
| 11~12 | 좌표와 색칠로 그림 그리기, 나만의 작품 완성하기 |

수학의 **각도·좌표·나머지**가 자연스럽게 연결됩니다. 정사각형을 그리려면 360 ÷ 4 = 90도가 필요하다는 것을
계산이 아니라 **직접 그려 보며** 알게 됩니다.

---

## 개인정보는 안전한가요?

- **수집하는 정보가 없습니다.** 회원가입도, 로그인도 없습니다.
- 아이가 쓴 코드와 진도는 **그 컴퓨터의 브라우저 안에만** 저장되고, 어디로도 전송되지 않습니다.
- 광고와 외부 링크가 없습니다.
- [내 진도] 창에서 이름을 적을 수 있지만 **선택 사항**이며, 이것도 그 브라우저 안에만 남습니다.

## 가정에서 도와주실 점

### 1. 정답을 알려 주지 마세요

가장 중요한 부탁입니다. 아이가 막혔을 때는 답 대신 **질문**을 해 주세요.

- "화면에 뭐라고 나왔어? 같이 읽어 볼까?"
- "어느 줄에서 멈췄대?"
- "숫자 하나만 바꿔서 실행하면 어떻게 될 것 같아?"

오류 메시지를 읽고 스스로 고치는 경험이 이 수업의 핵심입니다.

### 2. "틀려도 괜찮다"고 말해 주세요

코딩은 **바꾸고 → 실행하고 → 관찰하는** 일의 반복입니다.
프로그램이 망가지는 일은 없으니 마음껏 실험하게 해 주세요.

### 3. 작품을 봐 주세요

그림판 위 **[그림 저장]** 버튼으로 작품을 그림 파일로 저장할 수 있습니다.
완성한 그림을 보여 달라고 하고, **"이건 어떻게 만든 거야?"** 라고 물어봐 주세요.
설명하는 것이 아이에게 가장 좋은 복습입니다.

### 4. 기기를 바꿀 때

집 컴퓨터와 학교 컴퓨터의 저장 내용은 서로 연결되지 않습니다.
옮기고 싶다면 [내 진도] → **[파일로 저장]** 한 뒤, 다른 컴퓨터에서 **[파일 불러오기]** 를 하면 됩니다.

## 이 다음은 무엇인가요?

한글로 익힌 낱말에는 모두 **영어 짝**이 있습니다.

| 한글 | 영어 |
|---|---|
| 출력 | print |
| 만약 | if |
| 반복 | for |
| 함수 | def |

낱말에 마우스를 올리면 짝이 되는 영어 낱말이 나옵니다. **영어로 써도 똑같이 실행됩니다.**
12차시를 마치면 파이썬(Python)으로 넘어갈 준비가 됩니다.
