# 🐢 한글코딩 놀이터

초등학생이 처음 코딩을 배울 때 쓰는, **브라우저에서 바로 실행되는 한글 프로그래밍 언어(한글랭) 웹 플랫폼**입니다.
설치·로그인 없이 링크만 열면 코드를 쓰고, 거북이 캐릭터가 그림을 그리는 과정을 눈으로 바로 볼 수 있습니다.

- **즉시 실행**: 클라이언트 사이드 인터프리터(TypeScript 자체 구현) — 서버, WASM 불필요
- **시각적 피드백**: HTML5 Canvas 거북이 그래픽, 실행 중인 줄 하이라이트, 그려지는 과정 애니메이션
- **친절한 실패**: 스택 트레이스 대신 "5번째 줄: '끝'을 안 적은 곳이 있어요" 같은 아이 눈높이 안내 + 빨간 밑줄
- **작은 성공 경험**: 난이도순 미션 8개, 완료 시 축하 색종이와 뱃지
- **실제 코딩 브리지**: 모든 한글 키워드에 영어 짝이 있어요 — `if`, `print`, `turtle.forward(100)` 처럼 **영어로 써도 똑같이 실행**되고, 에디터에서 단어에 마우스를 올리면 짝 단어를 알려줘요
- **교재식 학습**: 미션마다 배우기(생활 속 비유·핵심·자주 하는 실수) → 따라하기(단계별 코드) → 퀴즈 → 도전 과제 4단계 구성
- **VS Code식 자동완성**: 타이핑하면 바로 제안 목록, `캐릭터.` 점을 찍으면 명령 목록, 내가 만든 변수/함수도 제안 + 한글 설명 패널
- **3D 이모지 UI**: 시스템 이모티콘 대신 입체 3D 이모지(Microsoft Fluent Emoji, MIT)를 번들해 어떤 기기에서도 같은 모습
- **자동 저장**: localStorage 기반 — 새로고침해도 미션별 코드 유지

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (기본 http://localhost:5173)
```

### 검사/테스트

```bash
npm run smoke      # 언어 엔진 스모크 테스트 (문법/그래픽/에러 메시지/영어 브리지)
npx tsc --noEmit   # 타입 체크
```

### 배포 (정적 호스팅)

```bash
npm run build      # dist/ 생성 (타입체크 포함)
npm run preview    # 빌드 결과 미리보기
```

`dist/` 폴더를 Vercel, Netlify, GitHub Pages 등 아무 정적 호스팅에 올리면 끝입니다.
`base: './'` 로 빌드되므로 하위 경로(예: GitHub Pages 프로젝트 페이지)에서도 동작합니다.

## 기술 스택

| 영역 | 선택 |
|---|---|
| 프레임워크 | React 19 + Vite 7 + TypeScript |
| 코드 에디터 | CodeMirror 6 (한글 키워드 하이라이팅, `끝` 자동 들여쓰기, 한글 자동완성 스니펫, 호버 툴팁) |
| 언어 엔진 | 자체 구현 렉서 → 재귀 하강 파서 → 트리 워킹 인터프리터 (`src/lang/`) |
| 그래픽 | HTML5 Canvas 애니메이션 플레이어 (`src/turtle/player.ts`) |
| 스타일 | Tailwind CSS 4 |

무한 루프/폭주 방지: 실행 스텝 20만 회, 그리기 명령 5,000개, 출력 1,000줄, 재귀 200단계 제한.

## 한글랭 문법 요약

```
# 주석

# 변수
이름 = "민준"
나이 = 10

# 출력 (쉼표로 여러 값)
출력("안녕하세요")
출력("나이:", 나이)

# 조건문
만약 나이 >= 10 이면
    출력("고학년")
아니면 만약 나이 >= 8 이면
    출력("중학년")
아니면
    출력("저학년")
끝

# 반복문 (범위, 끝 값 포함)
반복 i = 1 부터 5
    출력(i)
끝

# 반복문 (조건)
동안 i < 10
    i = i + 1
끝

# 함수 (재귀 지원)
함수 더하기(a, b)
    반환 a + b
끝

# 리스트
숫자들 = [1, 2, 3]
출력(숫자들[0])        # 첫 칸은 0번
출력(길이(숫자들))
추가(숫자들, 4)
숫자들[0] = 9

# 논리/비교
그리고  또는  아니다  참  거짓
==  !=  <  <=  >  >=      # 산술: + - * / %

# 내장 함수
길이(리스트또는글자)  추가(리스트, 값)  무작위(1, 10)  반올림(3.7)
```

### 캐릭터(거북이) 명령

```
캐릭터.앞으로(거리)      캐릭터.뒤로(거리)
캐릭터.오른쪽(각도)      캐릭터.왼쪽(각도)
캐릭터.색깔("빨강")      캐릭터.굵기(5)
캐릭터.펜올리기()        캐릭터.펜내리기()
캐릭터.말하기("안녕!")   # 말풍선
```

쓸 수 있는 색: 빨강, 주황, 노랑, 초록, 연두, 파랑, 하늘, 남색, 보라, 분홍, 갈색, 검정, 하양, 회색, 금색, 은색 (+ `#hex`)

정사각형 예시:

```
반복 i = 1 부터 4
    캐릭터.앞으로(100)
    캐릭터.오른쪽(90)
끝
```

### 영어 키워드로도 쓸 수 있어요 (실제 코딩 브리지)

한글 단어마다 실제 코딩(파이썬 등)에서 쓰는 영어 짝이 있고, **어느 쪽으로 써도 똑같이 실행**됩니다. 섞어 써도 돼요.
에디터에서 단어에 마우스를 올리면 짝 단어를 툴팁으로 알려줍니다.

| 한글 | 영어 | 한글 | 영어 |
|---|---|---|---|
| 만약 / 이면 | if / then | 출력 | print |
| 아니면 만약 / 아니면 | elif / else | 길이 / 추가 | len / append |
| 끝 | end | 무작위 / 반올림 | random / round |
| 반복 / 부터 | for / to | 캐릭터 | turtle |
| 동안 | while | 앞으로 / 뒤로 | forward / back |
| 함수 / 반환 | def / return | 오른쪽 / 왼쪽 | right / left |
| 그리고 / 또는 / 아니다 | and / or / not | 색깔 / 굵기 | color / width |
| 참 / 거짓 | true / false | 펜올리기 / 펜내리기 / 말하기 | penup / pendown / say |

```
# 위의 정사각형과 완전히 같은 코드
for i = 1 to 4
    turtle.forward(100)
    turtle.right(90)
end
```

단어 짝은 [src/lang/aliases.ts](src/lang/aliases.ts) 에서 관리합니다.

## 미션 구성 (8개, 난이도순)

1. 👋 첫 출력 — 컴퓨터에게 말 시키기
2. 🙋 변수 — 이름표 붙은 상자
3. 🎯 조건문 — 갈림길에서 고르기
4. 🟦 반복문 — 정사각형 그리기
5. ⭐ 각도의 마법 — 별 그리기
6. 🧩 함수 — 나만의 명령 레시피
7. 🌈 리스트 — 값들의 기차
8. 🎨 종합 — 나만의 그림 그리기

각 미션은 실제 코딩 교재처럼 4단계로 구성됩니다:

1. **배우기** — 생활 속 비유로 개념 설명, 꼭 기억할 핵심, 자주 하는 실수(틀린 코드 → 고친 코드 → 이유), 한 줄 정리
2. **따라하기** — 단계별 지시문과 그 단계까지의 전체 코드([넣기] 버튼으로 에디터에 삽입)
3. **퀴즈** — 개념 확인 객관식 1문항, 정답/오답 즉시 피드백
4. **도전** — 응용 과제 + 접었다 펴는 힌트

완료 조건을 만족하면 축하 애니메이션과 뱃지를 줍니다. 미션·교재 데이터는 `src/missions/missions.ts` 에서 수정/추가할 수 있습니다.

## 프로젝트 구조

```
src/
├── lang/            # 한글랭 언어 엔진 (브라우저/Node 겸용, DOM 의존 없음)
│   ├── lexer.ts     #   토크나이저 (영어 키워드 → 한글 정규화 포함)
│   ├── parser.ts    #   재귀 하강 파서 (친절한 문법 에러)
│   ├── interpreter.ts #  실행기 + 내장함수 + 캐릭터 명령 → 효과 목록
│   ├── aliases.ts   #   한글 ↔ 영어 단어 짝
│   ├── run.ts       #   parse+run 헬퍼
│   ├── colors.ts    #   한글 색 이름표
│   └── errors.ts    #   KidError (아이 눈높이 메시지 + 줄 번호)
├── turtle/player.ts # 효과 목록을 캔버스 애니메이션으로 재생
├── editor/          # CodeMirror 6 설정 (하이라이팅/들여쓰기/자동완성/에러 밑줄/호버 툴팁)
├── missions/        # 미션 8개 + 교재 데이터(배우기/따라하기/퀴즈/도전) + 완료 판정
├── ui/emoji.tsx     # 3D 이모지 컴포넌트 (assets/emoji/*.png)
├── components/      # 상단바, 미션 교재 패널, 그림판, 출력 창, 축하 효과, 도움말
└── App.tsx          # 실행 파이프라인과 상태 연결
scripts/smoke.ts     # 엔진 스모크 테스트 (npm run smoke)
```
