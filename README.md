# 🐢 한글코딩 놀이터

[놀이터 열기](https://korean-coding-platform.vercel.app) · [예제 실험실과 검증 기록](docs/UPGRADE.md)

**예제 실험실:** 숫자를 바꾸며 도형의 회전각과 누적 합을 예상하고, 설명을 확인한 뒤 에디터에서 실행해 볼 수 있습니다.

초등학생(9~13세)이 처음 코딩을 배울 때 쓰는, **브라우저에서 바로 실행되는 한글 프로그래밍 언어(한글랭) 웹 플랫폼**입니다.
설치·로그인 없이 링크만 열면 코드를 쓰고, 거북이 캐릭터가 그림을 그리는 과정을 눈으로 바로 볼 수 있습니다.

- **즉시 실행**: 클라이언트 사이드 인터프리터(TypeScript 자체 구현) — 서버, WASM 불필요
- **완전 자립**: 글꼴까지 사이트 안에 담아 외부 요청이 0건 — 학교망에서 CDN이 막혀도, 오프라인에서도 그대로 동작
- **시각적 피드백**: HTML5 Canvas 거북이 그래픽, 실행 중인 줄 하이라이트, 그려지는 과정 애니메이션, 그림이 커지면 자동 축소
- **친절한 실패**: 스택 트레이스 대신 "1번째 줄에서 연 괄호 '('를 닫지 않았어요" 같은 아이 눈높이 안내 + 그 줄 빨간 밑줄
- **대화하는 프로그램**: `입력( )` · `숫자입력( )` 으로 컴퓨터가 아이에게 물어봅니다 — 진짜 게임과 계산기를 만들 수 있어요
- **거북이 화가**: 원·좌표 이동·집으로·색칠·글쓰기·점찍기 등 20가지 그리기 명령
- **길 안내**: 화면 위의 '다음 할 일' 띠가 지금 무엇을 해야 하는지 늘 알려 줍니다 (① 배우기 → ② 따라하기 → ③ 실행하기 → 완료 시 [다음 미션으로 →])
- **교재식 학습**: 12차시 커리큘럼. 미션마다 배우기(비유·핵심·자주 하는 실수) → 따라하기(단계별 코드) → 퀴즈 → 도전 4단계
- **교사용 도구**: `?teacher=1` 로 성취기준·지도 포인트·언플러그드 활동·예시 답안·평가 루브릭을 보고 인쇄
- **진도 관리**: 내 진도표 보기·인쇄, 기기를 바꿀 때 파일로 저장/불러오기, 작품 PNG 저장
- **정직한 판정**: 시작 코드를 그대로 실행만 해서는 미션이 완료되지 않습니다(주석으로 우회하는 것도 막습니다)
- **영어 단어 브리지**: `if`, `print`, `turtle.forward(100)` 처럼 **영어로 써도 똑같이 실행**되고, 단어에 마우스를 올리면 짝 단어와 파이썬과의 차이를 알려줘요
- **VS Code식 자동완성**: 타이핑하면 바로 제안, `캐릭터.` 점을 찍으면 명령 목록 + 한글 설명, 내가 만든 변수/함수도 제안
- **3D 이모지 UI**: 시스템 이모티콘 대신 입체 3D 이모지(Microsoft Fluent Emoji, MIT)를 번들해 어떤 기기에서도 같은 모습
- **자동 저장**: localStorage 기반 — 새로고침해도 미션별 코드 유지

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (기본 http://localhost:5173)
```

### 검사/테스트

```bash
npm run smoke      # 엔진 + 미션 판정 스모크 테스트 150종
npx tsc --noEmit   # 타입 체크
```

`npm run smoke`는 문법·의미론·에러 메시지·줄 번호뿐 아니라, **12개 미션 각각에 대해**
"시작 코드만으로는 미완료 / 따라하기 마지막 단계로는 완료 / 예시 코드로 완료 / 영어로 쓴 예시로도 완료"와
교재 힌트에 적힌 코드가 실제로 실행되는지까지 검사합니다. 교재를 고치면 이 테스트가 먼저 알려 줍니다.

### 배포 (정적 호스팅)

```bash
npm run build      # dist/ 생성 (타입체크 포함)
npm run preview    # 빌드 결과 미리보기
```

`dist/` 폴더를 Vercel, Netlify, GitHub Pages, 교내 서버 등 아무 정적 호스팅에 올리면 끝입니다.
`base: './'` 로 빌드되므로 하위 경로(예: GitHub Pages 프로젝트 페이지)나 파일 서버에서도 동작합니다.
외부 요청이 전혀 없으므로 인터넷이 끊긴 교실에서도 그대로 쓸 수 있습니다.

## 교실에서 쓰기

- **차시 지도안·성취기준·평가 루브릭**: [docs/교사용-지도안.md](docs/교사용-지도안.md) (12차시 계획, 언플러그드 활동, 루브릭)
- **보호자 안내문**: [docs/보호자-안내문.md](docs/보호자-안내문.md) (그대로 인쇄해 가정으로)
- **교사용 화면**: 주소 끝에 `?teacher=1` 을 붙이면 상단에 [교사용] 버튼이 생깁니다.
  차시별 성취기준·지도 포인트·자주 막히는 곳·언플러그드 활동·**예시 답안 코드·퀴즈 정답·평가 루브릭**을 보고 인쇄할 수 있습니다.
  이 버튼은 학생 화면(주소에 붙이지 않았을 때)에는 **나타나지 않습니다.**
- **진도 확인**: 학생이 상단 뱃지(N/12)를 누르면 자기 진도표가 나옵니다. 글로 복사·파일 저장·인쇄가 가능합니다.
- **저장 위치**: 학생이 쓴 코드와 뱃지는 **그 브라우저 안에만** 저장됩니다. 서버로 전송되는 개인정보는 없습니다.
- **공용 PC 정리**: 주소 끝에 `?reset=1` 을 붙여 열면(예: `https://.../?reset=1`) 저장된 코드·뱃지를 모두 지우고 시작합니다.
  컴퓨터실 바탕화면 바로가기를 이 주소로 만들어 두면 매 교시 깨끗한 상태로 시작할 수 있습니다.
  📖 도움말 아래의 **[처음부터 다시 시작]** 버튼이나 브라우저 시크릿 창을 써도 됩니다.

- **기기를 바꿀 때**: [내 진도] → [파일로 저장] 후, 다른 컴퓨터에서 [파일 불러오기].
- **상단바 버튼**: [그림 지우기]는 그림판과 출력 창만 지웁니다(코드는 그대로). 재생이 길어지면 [바로 완성]으로 즉시 끝낼 수 있습니다.
- **작품 제출**: 그림판의 [그림 저장]으로 PNG 파일을 내려받아 게시판에 모으면 산출물 공유 활동이 됩니다.

## 기술 스택

| 영역 | 선택 |
|---|---|
| 프레임워크 | React 19 + Vite 7 + TypeScript |
| 코드 에디터 | CodeMirror 6 (한글 키워드 하이라이팅, 블록 자동 들여쓰기, 자동완성, 한↔영 호버 툴팁, 에러 밑줄·거터) |
| 언어 엔진 | 자체 구현 렉서 → 재귀 하강 파서 → 트리 워킹 인터프리터 (`src/lang/`) |
| 그래픽 | HTML5 Canvas 애니메이션 플레이어 (`src/turtle/player.ts`) |
| 스타일 | Tailwind CSS 4 + 자체 호스팅 글꼴 |

**안전 한계** (브라우저가 멈추지 않도록): 실행 시간 1초·스텝 500만 회, 반복 범위 200만 회,
그리기 명령 5,000개, 출력 1,000줄, 재귀 200단계, 리스트/글자 100,000개.
한계에 걸리면 "무엇을 줄여야 하는지"를 그 반복문 줄과 함께 알려 줍니다.

## 한글랭 문법 요약

```
# 주석

# 변수
이름 = "민준"
나이 = 10

# 출력 (쉼표로 여러 값)
출력("안녕하세요")
출력("나이:", 나이)

# 입력 — 컴퓨터가 물어보고 답을 받아요
이름 = 입력("이름이 뭐예요?")        # 답을 글자로
나이 = 숫자입력("몇 살이에요?")      # 답을 숫자로 (계산할 값)

# 조건문
만약 나이 >= 10 이면
    출력("고학년")
아니면 만약 나이 >= 8 이면
    출력("중학년")
아니면
    출력("저학년")
끝

# 반복문 (범위, 끝 값 포함)
반복 i = 1 부터 5
    출력(i)
끝

# 반복문 (조건)
동안 i < 10
    i = i + 1
끝

# 함수 (재귀 지원, 아래에 정의해도 위에서 부를 수 있음)
함수 더하기(a, b)
    반환 a + b
끝

# 리스트
숫자들 = [1, 2, 3]
출력(숫자들[0])        # 첫 칸은 0번
출력(길이(숫자들))
추가(숫자들, 4)
숫자들[0] = 9

# 논리/비교
그리고  또는  아니다  참  거짓
==  !=  <  <=  >  >=      # 산술: + - * / %

# 내장 함수
길이(리스트또는글자)  추가(리스트, 값)  무작위(1, 10)  반올림(3.7)
```

### 캐릭터(거북이) 명령

```
# 움직이기
캐릭터.앞으로(거리)      캐릭터.뒤로(거리)
캐릭터.오른쪽(각도)      캐릭터.왼쪽(각도)
캐릭터.이동(x, y)        # 그 좌표로 (오른쪽 x+, 위쪽 y+ — 수학과 같아요)
캐릭터.집으로()          # 가운데(0,0)로 돌아가 위를 보기
캐릭터.방향(각도)        # 0=위, 90=오른쪽, 180=아래, 270=왼쪽

# 그리기
캐릭터.원(반지름)        # 지금 자리를 가운데로 동그라미
캐릭터.점찍기(크기)
캐릭터.채우기시작() … 캐릭터.채우기끝()   # 그 사이 도형 안쪽 색칠
캐릭터.글쓰기("안녕")    # 그림판에 글자 (그림으로 남음)

# 펜과 모습
캐릭터.색깔("빨강")      캐릭터.굵기(5)
캐릭터.펜올리기()        캐릭터.펜내리기()
캐릭터.숨기기()          캐릭터.보이기()
캐릭터.지우기()          # 그린 그림 모두 지우기
캐릭터.말하기("안녕!")   # 말풍선
```

쓸 수 있는 색: 빨강, 주황, 노랑, 초록, 연두, 파랑, 하늘, 남색, 보라, 분홍, 갈색, 검정, 하양, 회색, 금색, 은색
(영어 이름 `red`, `blue`, `green` … 과 `#hex` 도 됩니다)

정사각형 예시:

```
반복 i = 1 부터 4
    캐릭터.앞으로(100)
    캐릭터.오른쪽(90)
끝
```

### 영어 단어로도 쓸 수 있어요

한글 단어마다 짝이 되는 영어 단어가 있고, **어느 쪽으로 써도 똑같이 실행**됩니다. 섞어 써도 됩니다.
에디터에서 단어에 마우스를 올리면 짝 단어를 툴팁으로 알려 줍니다.

| 한글 | 영어 | 한글 | 영어 |
|---|---|---|---|
| 만약 / 이면 | if / then | 출력 | print |
| 아니면 만약 / 아니면 | elif / else | 길이 / 추가 | len / append |
| 끝 | end | 무작위 / 반올림 | random / round |
| 반복 / 부터 | for / to | 캐릭터 | turtle |
| 동안 | while | 앞으로 / 뒤로 | forward / back |
| 함수 / 반환 | def / return | 오른쪽 / 왼쪽 | right / left |
| 그리고 / 또는 / 아니다 | and / or / not | 색깔 / 굵기 | color / width |
| 참 / 거짓 | true / false | 펜올리기 / 펜내리기 / 말하기 | penup / pendown / say |
| 입력 / 숫자입력 | input / inputNumber | 원 / 이동 / 집으로 | circle / goto / home |
| | | 채우기시작 / 채우기끝 / 글쓰기 | begin_fill / end_fill / write |

```
# 위의 정사각형과 완전히 같은 코드
for i = 1 to 4
    turtle.forward(100)
    turtle.right(90)
end
```

**파이썬과의 관계 (정직하게)**: `print` · `if` · `for` · `def` · `turtle.forward` 는 파이썬에서도 같은 단어입니다.
다만 파이썬은 블록을 `끝`(`end`)으로 닫지 않고 **콜론(:)과 들여쓰기**로 나누고, 반복도 `for i in range(1, 6):` 형태로 씁니다.
호버 툴팁이 이런 차이를 그때그때 알려 줍니다. 단어 짝은 [src/lang/aliases.ts](src/lang/aliases.ts) 에서 관리합니다.

## 미션 구성 (12차시, 난이도순)

| 차시 | 미션 | 핵심 개념 |
|---|---|---|
| 1 | 첫 출력 — 컴퓨터에게 말 시키기 | 순차 실행, 명령의 형태 |
| 2 | 변수 — 이름표 붙은 상자 | 변수, 대입(=) |
| 3 | 입력 — 컴퓨터가 나에게 물어봐요 | 입력, 글자와 숫자의 차이 |
| 4 | 조건문 — 갈림길에서 고르기 | 선택 구조, 비교(==) |
| 5 | 반복문 — 정사각형 그리기 | 반복 구조, 360÷n |
| 6 | 각도의 마법 — 별 그리기 | 변수 하나의 영향, 실험 태도 |
| 7 | 반복 속 갈림길 — 무늬 만들기 | 중첩(반복+조건), 나머지(%) |
| 8 | 동안 반복 — 맞힐 때까지 물어보기 | 조건 반복, 무한 반복 이해 |
| 9 | 함수 — 나만의 명령 레시피 | 함수 정의/호출, 매개변수 |
| 10 | 리스트 — 값들의 기차 | 리스트, 0부터 세기 |
| 11 | 거북이 화가 — 원, 좌표, 색칠 | 좌표평면, 도구 확장 |
| 12 | 종합 — 나만의 그림 그리기 | 통합·설계·공유 |

각 미션은 실제 코딩 교재처럼 4단계로 구성됩니다:

1. **배우기** — 생활 속 비유, 꼭 기억할 핵심, 자주 하는 실수(틀린 것 → 고친 것 → 이유), 한 줄 정리
2. **따라하기** — 단계별 지시문과 그 단계까지의 전체 코드([넣기] 버튼으로 에디터에 삽입)
3. **퀴즈** — 개념 확인 객관식, **고른 오답마다 다른 설명**으로 오개념을 바로잡음
4. **도전** — 응용 과제 + 접었다 펴는 힌트(실행되는 예시 코드 포함)

완료하면 색종이가 날리고, 화면 위 '다음 할 일' 띠가 초록으로 바뀌며 **[다음 미션으로 →]** 버튼이 나옵니다.
축하 문구가 결과(출력 창·그림판)를 가리지 않도록 안내는 항상 화면 위쪽 띠에서만 보여 줍니다.
조건을 못 채우면 같은 띠가 목표를 다시 알려 줍니다.
미션·교재 데이터는 [src/missions/missions.ts](src/missions/missions.ts) 에서 수정/추가할 수 있습니다.

## 프로젝트 구조

```
src/
├── lang/            # 한글랭 언어 엔진 (브라우저/Node 겸용, DOM 의존 없음)
│   ├── lexer.ts     #   토크나이저 (영어 키워드 → 한글 정규화, 원문 raw 보존)
│   ├── parser.ts    #   재귀 하강 파서 (괄호·조건·붙여쓰기 등 상황별 에러)
│   ├── interpreter.ts #  실행기 + 내장함수 + 캐릭터 명령 → 효과 목록
│   ├── aliases.ts   #   한글 ↔ 영어 단어 짝 + 파이썬 차이 메모
│   ├── run.ts       #   parse+run 헬퍼
│   ├── colors.ts    #   한글/영어 색 이름표
│   └── errors.ts    #   KidError (아이 눈높이 메시지 + 줄 번호)
├── turtle/player.ts # 효과 목록을 캔버스 애니메이션으로 재생 (자동 축소·바로 완성)
├── editor/          # CodeMirror 6 설정 (하이라이팅/들여쓰기/자동완성/에러 밑줄/호버 툴팁)
├── missions/
│   ├── missions.ts  #   미션 12개 + 교재 데이터 + 토큰 기반 완료 판정
│   └── teaching.ts  #   교사용: 성취기준·지도 포인트·언플러그드·루브릭
├── ui/emoji.tsx     # 3D 이모지 컴포넌트 (assets/emoji/*.png)
├── components/      # 상단바, 교재 패널, 그림판, 출력 창, 질문 창, 진도표, 교사용 자료, 도움말
├── storage.ts       # localStorage 저장 (코드/뱃지/패널 상태, 모두 지우기)
└── App.tsx          # 실행 파이프라인과 상태 연결
public/fonts/        # 자체 호스팅 글꼴 (한글 전체 서브셋, 4개 약 1.1MB)
scripts/smoke.ts     # 엔진 + 미션 판정 테스트 (npm run smoke)
docs/                # 현황 분석 보고서와 개선 계획
```
